语义 ID 如何连接 LLM 与序列推荐

分类：推荐系统|2026-09-19|LLM4RecSemantic ID

传统 ID 表征擅长捕捉平台内协同信号，却难以处理冷启动；LLM 表征有丰富语义，却未必理解真实业务中的转化、地理和共现关系。这篇笔记从 SIDSRec、SICSRec 和本地生活推荐实践出发，讨论语义 ID 为什么处在内容语义、协同过滤和工业推荐系统的交界处。
